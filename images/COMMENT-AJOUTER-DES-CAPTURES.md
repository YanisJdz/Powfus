# Ajouter des captures d'écran

Le README attend deux images (les blocs sont prêts, en commentaire) :

- `apercu-liste.png` — la liste des comptes (image principale)
- `apercu-reglages.png` — le panneau de réglages

## Comment faire

1. Lance Powfus.
2. Capture la fenêtre avec **Outil Capture d'écran** de Windows (`Win + Maj + S`).
3. **Anonymise** avant de publier : la liste montre tes vrais pseudos et personnages.
   Le plus simple est de flouter les noms, ou de faire la capture avec des comptes
   de test. (Rappel : ce repo est **public**.)
4. Enregistre l'image ici, sous le bon nom, puis dans `README.md` **décommente** le
   bloc `<div align="center">…</div>` correspondant (retire les balises `<!--` et `-->`).

Largeur conseillée : ~1200 px, format PNG.
